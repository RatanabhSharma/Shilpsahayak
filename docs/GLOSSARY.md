# Glossary

- **Slicer**: Software that converts a 3D model into instructions (G-code) for a 3D printer.
- **R2**: Cloudflare's object storage service, comparable to AWS S3.
- **Worker**: Cloudflare edge serverless function.
- **SPA**: Single Page Application (the React frontend).
- **Idempotency Key**: A unique key generated by the frontend to ensure a request (like creating a payment) is processed exactly once, even if the network request is retried.
- **G-code**: The language used to instruct the 3D printers how to move.
- **Infill**: The internal structure of a 3D printed object, usually defined as a percentage.
