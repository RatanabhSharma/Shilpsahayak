## Overview
Shilp Sahayak is a full-stack, production e-commerce and on-demand precision manufacturing platform based in India. It enables users to browse catalog products (lighting, planters, desk accessories), order custom 3D printing with real-time 3D model parsing and quoting (Shilp Studio), pay securely via Razorpay, and manage business operations through an integrated Admin CMS.

## Components & Modules

### 1. Storefront & Hero Media Architecture
- **Location:** `frontend/src/pages/storefront/Home.tsx`
- **Hero Implementation:**
  - Dynamic media mode supporting video (`demo_video2.mp4` / custom URL), static image, or slideshow.
  - Video is deferred until user interaction or viewport idle (`shouldLoadVideo`).
  - Active `IntersectionObserver` pauses video playback when scrolled out of view to save GPU/CPU.
  - 3D CAD visualization is lazily loaded via `Hero3DCanvas.tsx` (`React.lazy`).
- **Initial Data Optimization:**
  - `useProducts` loads with `INITIAL_CATALOG_PRODUCTS` instantly.
  - `useHomepage` hydrates synchronously with `DEFAULT_HOMEPAGE_SETTINGS` before Firestore responds.

### 2. Shilp Studio (Custom 3D Printing Pipeline)
- **Location:** `frontend/src/pages/storefront/CustomPrinting.tsx` & `frontend/src/services/`
- **Responsibilities:**
  - Client-side CAD parsing for `.stl`, `.obj`, and `.3mf` (Bambu multi-material).
  - Geometry analysis (bounding box, volume calculation, weight estimation).
  - Deterministic price quoting via `services/pricing/calculateQuote.ts`.
  - Secure CAD upload to Cloudflare R2 via signed endpoints.
  - Protected manual quotation workflow (governed by `ANTIGRAVITY.md`).

### 3. Cart & Payment Pipeline
- **State Store:** `frontend/src/store.ts` (persisted in `localStorage` via Zustand middleware).
- **Payment Service:** `frontend/src/services/paymentService.ts`
- **Flow:**
  1. Customer reviews items in Cart or Buy-Now.
  2. Frontend sends payload to Cloudflare Worker `/create-payment-order`.
  3. Worker verifies pricing against Firestore, contacts Razorpay API, and creates a pending order.
  4. Razorpay Checkout modal handles payment.
  5. Worker verifies payment signature on `/verify-payment` and marks order Paid.

### 4. Admin CMS Architecture
- **Layout:** `frontend/src/components/AdminLayout.tsx`
- **Protection:** `frontend/src/components/ProtectedRoute.tsx` verifies admin claim via `useUserRole.ts`.
- **Pages:**
  - `Dashboard`: Revenue, order velocity, inventory health.
  - `Catalog`: CRUD for products, image uploads, stock overrides.
  - `AdminHome`: Visual homepage configuration (hero copy, media toggles, section order).
  - `Orders` / `OrderDetail`: Order state machine and tracking number updates.
  - `Quotes`: Review of Shilp Studio custom fabrication requests.

## Performance State & Optimizations

- **Route Code Splitting:** Every page route (storefront and admin) is lazy-loaded with `React.lazy` and wrapped in `Suspense` with graceful skeletons.
- **Vite Rollup Chunks:** Dedicated vendor splits for `vendor-firebase`, `vendor-framer`, and `vendor-tanstack` to keep individual bundle sizes controlled.
- **Cache Pre-warming:** TanStack React Query utilizes `initialData` with static fallbacks so the initial paint never blocks on network requests.
- **Video & 3D Deferral:** Hero video and Three.js canvas are isolated from critical rendering path.
