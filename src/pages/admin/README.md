# Clean Admin Code

These files are the current functional admin implementation, cleaned conservatively.
They retain the existing Firebase/React Query logic and imports; no business logic was replaced
with the static prototype implementation.

Files:
- AdminLogin.tsx
- Dashboard.tsx
- Orders.tsx
- OrderDetail.tsx
- Quotes.tsx
- Catalog.tsx
- Inventory.tsx
- Customers.tsx

should not replace the functional files unless their UI is explicitly merged into the Firebase
implementation.
